# Startup Pulse: Burn Rate, Runway & Growth Dashboard

## Project Overview
Startup Pulse is an interactive Tableau dashboard project built to analyze the financial health and operational performance of startups. The dashboard focuses on key business metrics such as revenue, expenses, burn rate, runway, and health score to support better business decision-making.

This project covers the complete analytics workflow:
- understanding and preparing startup financial data
- cleaning and organizing the dataset
- creating meaningful business KPIs
- building an interactive Tableau dashboard for financial insights

---

## Objective
The main objective of this project is to monitor startup performance and identify financial risks by analyzing:

- Revenue trends over time
- Total operating expenses
- Burn rate across startups
- Runway months available
- Department-wise spending
- Startup health score
- Risk level distribution

---

## Project Workflow

### 1. Data Cleaning and Preparation
Before building the dashboard, the dataset was cleaned and prepared to ensure accuracy and consistency.

#### Data cleaning steps performed:
- Removed unnecessary inconsistencies in column naming
- Verified numeric fields such as Revenue, Burn Rate, Total Expense, and Runway Months
- Checked for missing values and ensured the dataset was dashboard-ready
- Organized date/month values for time-based analysis
- Structured expense categories for easy comparison
- Ensured dimensions such as Industry, City, Funding Stage, and Risk Level were properly categorized

This step helped make the data suitable for Tableau visualization and business analysis.

---

### 2. Tableau Dashboard Development
After cleaning the data, an interactive Tableau dashboard was created to visualize startup financial performance.

#### Dashboard KPIs:
- Total Revenue
- Total Expense
- Average Burn Rate
- Average Runway Months
- Average Health Score

#### Dashboard Visualizations:
- Revenue vs Expense Trend Over Time
- Burn Rate by Startup
- Department-wise Expense Breakdown
- Runway Analysis by Startup
- Startup Health Score Comparison
- Risk Level Distribution

#### Interactive Filters:
- Industry
- Funding Stage
- City
- Startup Name
- Month
